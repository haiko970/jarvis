Affiche le site animé HOLENA « Les Ponts du Sel » dans une page WordPress.

== Utilisation ==

Dans une page, ajouter un bloc « Code court » et écrire : [holena]

Pour ouvrir directement une rubrique : [holena page="chili"]
(rubriques : guerande, perou, chili, label, livre, collectif)

Pour changer la hauteur du cadre : [holena hauteur="800px"]

Un lien « Ouvrir en plein écran » apparaît sous le site.
