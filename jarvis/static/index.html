🎙️ Sa voix

Crée un compte sur elevenlabs.io, puis Paramètres → API Keys → « Create API Key » (coche l'accès « Text to Speech »). Si la voix vient de la bibliothèque (« Voice Library »), ajoute-la d'abord à « My Voices ». Le texte des réponses est envoyé à ElevenLabs.

Les voix marquées ⭐ sont les plus naturelles.

Certaines voix naturelles ignorent ce réglage.

    🎓 Pronote

    1. Ouvre Pronote sur ton ordinateur (en passant par e-lyco comme d'habitude).
    2. En haut de la page, clique sur l'icône du téléphone portable / QR code (« Accéder à l'application mobile »).
    3. Choisis un code à 4 chiffres (retiens-le !) : Pronote affiche un QR code, valable quelques minutes.
    4. Appuie sur Windows + Maj + S et entoure le QR code : la capture est copiée.

    ☀️ Brief du jour

    Horaires estimés (à ~30 min près) : pratique pour la plage, pas pour la navigation.

    1. Ouvre script.google.com (connecté à ton compte Google) : un nouveau projet s'ouvre.
    2. Efface tout le texte qui s'y trouve, puis colle le code de Jarvis :
    3. Clique sur 💾 Enregistrer.
    4. En haut à droite : Déployer → Nouveau déploiement → roue ⚙️ → Application Web.
    5. « Exécuter en tant que » : Moi. « Qui a accès » : Tout le monde. Puis Déployer.
    6. Autoriser l'accès → choisis ton compte. Si Google affiche « Google n'a pas validé cette application », clique sur Paramètres avancés → Accéder à Projet sans titre → Autoriser. C'est normal : c'est ton propre script.
    7. Copie l'URL de l'application Web (elle finit par /exec) et colle-la ci-dessous.

    Ton agenda Google est inclus : pas besoin du lien iCal plus bas.
