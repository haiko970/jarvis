🎙️ Sa voix

Crée un compte sur elevenlabs.io, puis Paramètres → API Keys → « Create API Key » (coche l'accès « Text to Speech »). Si la voix vient de la bibliothèque (« Voice Library »), ajoute-la d'abord à « My Voices ». Le texte des réponses est envoyé à ElevenLabs.

Les voix marquées ⭐ sont les plus naturelles.

Certaines voix naturelles ignorent ce réglage.

    Sur sporteasy.net (sur ordinateur) : onglet Calendrier → bouton « Synchronisation Calendrier » → copie le lien et colle-le ici. Sur l'appli téléphone : Calendrier → « ⋯ » → « Synchroniser mon calendrier » → copier le lien. Ne partage ce lien avec personne.

    🛡️ Sentinelle

    Quand tu pars, dis « Jarvis, surveille le PC ». Si quelqu'un touche à la souris ou au clavier, il a 20 secondes pour taper ton code. Sinon : « Accès non autorisé », photo avec la webcam et PC verrouillé. Les photos sont rangées dans ton dossier Images → « Jarvis sentinelle ».

    La première fois, Edge te demande l'autorisation d'utiliser la caméra : clique sur « Autoriser ».
